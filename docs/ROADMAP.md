# Reel Deel Roadmap

## M0 — Production foundation
- System architecture and trust boundaries
- Core domain model and API contracts
- Jetson/Jev decision contract
- Identity, audit, observability, and failure requirements

## M1 — Dockside intake
- Camera/scale capture workflow
- Structured FishScan record
- Human review and correction
- Approved scan to Lot transition

## M2 — Marketplace
- Listing lifecycle
- Buyer discovery and lot detail
- Bid / buy workflow
- Sale confirmation and inventory state

## M3 — Settlement and provenance
- Payment/settlement boundary
- Chain adapter
- Provenance commitments
- Privacy requirements for commercially sensitive data

## M4 — Decision optimization
- Production evaluation data
- Laya local decision path where justified
- Jev escalation policy
- Calibration, drift monitoring, and model rollout controls

Each milestone must meet production acceptance criteria before the next layer depends on it.
